FORMATION 01

🟠 Apprendre le HTML

HTML signifie HyperText Markup Language. Il sert à organiser le contenu d'une page web.

01

Qu'est-ce que le HTML ?

Le HTML est un langage de balisage. Il permet de placer des titres, paragraphes, images, liens et autres éléments dans une page. Ce n'est pas un langage de programmation.

Une balise possède généralement une ouverture et une fermeture. Par exemple : 

<p>Bonjour le monde !</p>

La balise <p> indique un paragraphe. Le navigateur affiche son contenu comme du texte.

02

La structure d'une page HTML

Chaque page commence par une déclaration de type. La partie head contient les informations de la page. La partie body contient ce que voit le visiteur. 

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma première page</title>
</head>
<body>
  <h1>Bienvenue !</h1>
  <p>Voici mon premier site.</p>
</body>
</html>
03

Les titres et les paragraphes

HTML propose six niveaux de titres : h1, h2, h3, h4, h5 et h6. h1 est le titre principal, et h6 le niveau le moins important. 

<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<h3>Petite section</h3>
<p>Ceci est un paragraphe.</p>
<strong>Texte important</strong>
<em>Texte mis en valeur</em>

Titre principal (exemple)

Ceci est un paragraphe.

Texte important
04

Les liens et les images

La balise a crée un lien. L'attribut href précise sa destination. La balise img affiche une image et son attribut alt fournit une description. 

<a href="https://example.com">
  Visiter un site
</a>

<img src="photo.jpg"
     alt="Un paysage de montagne">

Attention : photo.jpg doit exister dans le dossier indiqué. La balise img n'a pas de fermeture.

05

Les listes HTML

Une liste ul contient des éléments à puces. Une liste ol contient des éléments numérotés. Chaque élément utilise la balise li. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Créer un fichier</li>
  <li>Écrire le HTML</li>
  <li>Ouvrir le navigateur</li>
</ol>
06

Les formulaires

Les formulaires permettent de saisir des données. input crée un champ, label décrit ce champ et button crée un bouton. 

<form>
  <label for="prenom">Prénom :</label>
  <input id="prenom"
         type="text"
         name="prenom"
         required>
  <button type="submit">
    Envoyer
  </button>
</form>

Un formulaire ne stocke pas automatiquement les données : il faut un traitement adapté.

07

Les balises sémantiques

Elles donnent du sens aux différentes parties d'une page et facilitent son organisation. 

<header>En-tête du site</header>
<nav>Navigation</nav>
<main>
  <section>
    <h2>Une section</h2>
    <article>Un article</article>
  </section>
</main>
<footer>Pied de page</footer>
FORMATION 02

🔵 Apprendre le CSS

CSS signifie Cascading Style Sheets. Il sert à personnaliser l'apparence du HTML.

01

Qu'est-ce que le CSS ?

HTML construit la structure d'une page. CSS permet de modifier les couleurs, les tailles, les espacements et les positions. 

/* Ceci est un commentaire CSS */
p {
  color: blue;
  font-size: 18px;
}

Ici, p est le sélecteur, color est une propriété et blue est sa valeur.

02

Relier HTML et CSS

La méthode recommandée consiste à utiliser un fichier CSS externe. Dans le head du HTML : 

<link rel="stylesheet" href="style.css">

Ensuite, dans style.css, tu peux écrire : 

body {
  background-color: #f1f5f9;
  color: #1e293b;
}
03

Les couleurs et les fonds

color change la couleur du texte. background-color change le fond. On peut utiliser des noms ou des codes hexadécimaux. 

h1 {
  color: #6366f1;
}

.card {
  background-color: #e0e7ff;
  border: 2px solid #6366f1;
  border-radius: 12px;
}
Voici une carte colorée !
04

Les polices et les textes

font-family définit la police, font-size la taille, font-weight l'épaisseur et text-align l'alignement. 

h1 {
  font-family: Arial, sans-serif;
  font-size: 36px;
  font-weight: bold;
  text-align: center;
}

p {
  line-height: 1.7;
}
05

Margin, padding et border

Chaque élément possède un modèle de boîte. padding crée de l'espace à l'intérieur, margin crée de l'espace à l'extérieur et border ajoute une bordure. 

.boite {
  margin: 20px;
  padding: 25px;
  border: 2px solid blue;
  border-radius: 10px;
}
Contenu avec padding et bordure
06

Les classes et les identifiants

Une classe se sélectionne avec un point. Un identifiant se sélectionne avec un #. Une même classe peut être utilisée plusieurs fois, tandis qu'un identifiant doit être unique. 

/* HTML */
<p class="important">Bonjour</p>
<h2 id="titre">Mon titre</h2>

/* CSS */
.important {
  color: red;
}

#titre {
  font-size: 28px;
}
07

Flexbox : aligner les éléments

Flexbox facilite l'alignement des éléments sur une ligne ou une colonne. gap définit l'espace entre les éléments. 

.conteneur {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 15px;
  flex-wrap: wrap;
}
Bloc 1 Bloc 2 Bloc 3
08

CSS Grid : créer une grille

Grid permet de disposer facilement plusieurs éléments en lignes et en colonnes. 

.grille {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

La valeur 1fr représente une fraction de l'espace disponible.

09

Le responsive design

Un site responsive s'adapte aux écrans d'ordinateur, de tablette et de téléphone. Les media queries appliquent des règles selon la taille de l'écran. 

.grille {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Pour les petits écrans */
@media (max-width: 768px) {
  .grille {
    grid-template-columns: 1fr;
  }
}
10

Les animations et transitions

transition permet de rendre les changements de style plus fluides, notamment au survol. 

.bouton {
  background: #6366f1;
  transition: transform 0.3s,
              background 0.3s;
}

.bouton:hover {
  background: #4338ca;
  transform: translateY(-4px);
}
